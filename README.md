# Russ Portfolio — Version 2

This is the new static foundation for Russel Lacerna's personal portfolio.

## Current stack
- HTML
- CSS
- Vanilla JavaScript
- LocalStorage for theme preference

## Current features
- Responsive portfolio layout
- Dark/light mode
- Mobile navigation
- Project cards and detail modal
- Existing project screenshots
- OJT / IT Support section
- Personal interests
- Contact email button
- Portfolio chatbot UI
- Local portfolio-aware chatbot prototype

## Important
The chatbot in this version is intentionally NOT connected to an external AI API yet.
It currently answers from a small local knowledge base in `script.js`.

Next development step:
1. Move portfolio content into structured data.
2. Build a backend API.
3. Connect an AI model.
4. Make the AI retrieve only portfolio-approved information.
5. Add a strict "don't invent information" rule.


## Sharing the portfolio
Because this version is a static HTML/CSS/JavaScript site, it can be hosted free with GitHub Pages.

`https://YOUR-USERNAME.github.io/`
